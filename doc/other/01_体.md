# 一、体（底层规律层）

> **体** 是底层规律集，分为两部分：
> - **Part 一 - 不可变公理（L0-L3）**：跨时代成立的数学、物理、生物与心理约束。不可被议价、不可被否定。
> - **Part 二 - 时代假说（L4）**：在 2025-2026 特定技术与商业环境下高度成立的判断，但附有显式失效条件，需按季度审查。
>
> 所有用（战略）与术（战术）必须从此处溯源，否则皆是在沙滩上建城堡。

## Part 一：不可变公理

### ⭕️ L0 抽象公理：上帝源代码（大模型的纯数学本质）

> **定位**：适用所有逻辑宇宙。大模型的最底层物理基座，不可逃避的数学指令。

### 体 01｜Transformer 本质公理（Next Token Prediction）

**底层事实**：所有 LLM 的底层运行机制完全一致——**预测下一个 Token 的概率分布**。它不理解语义，不记忆历史，不执行代码——它只在给定上下文中做 Token 级概率预测。

**物理含义**：

- LLM 的"能力"本质是训练语料中模式的压缩与复现。它在训练数据高频覆盖的领域表现极强，在长尾稀有领域高置信地出错
- LLM 对不同数据格式的处理效率存在数量级差异（→ 体 07 格式摩擦力）
- LLM 的自回归特性意味着每一步输出都成为下一步的输入（→ 体 10 错误复利）

> **LLM 不是"智能体"，它是"概率预测引擎"。Agent 的智能来自 LLM + Memory + Tools 的组合**

---

### 体 04｜幻觉不可消除定律

**底层事实**：LLM 基于概率分布生成，无法自我证伪。在没有外部反馈信号时，模型对自身输出保持盲目自信。"幻觉"不会因模型参数扩大而完全消除，只会以更隐蔽的形式存在。

> **LLM 的输出幻觉 ∝ 外部约束的缺失程度。你永远无法通过"更好地信任 AI"来回避幻觉，只能通过建立外部确定性护栏来拦截**

---

### 体 06｜深广不可兼得定律

**底层事实**：Transformer 的自注意力机制是总量有限的计算资源，在固定上下文窗口中被所有 Token 均摊，导致 **深度与广度的零和博弈**：

```
上下文中文件数 ↑ → 每个文件获得的注意力权重 ↓ → 跨文件逻辑推理精度 ↓
```

> **不存在既有全局视野又有局部精准的上下文配置，只有主动权衡**

---

### 体 10｜错误叠加复利定律

**底层事实**：LLM 是自回归系统，每一步输出都成为下一步的输入上下文。在多步骤 Agent 工作流中，**早期小偏差以复利方式指数级放大**：

```
步骤 1 的 5% 偏差 → 步骤 2 以 1.05x 基础推理 → 步骤 N 偏差 = 1.05^N（指数爆炸）
```

> **修复成本 ∝ 错误距链头的步骤数的指数。只有"链头验证"是高杠杆操作**

---

### ⚗️ L1 物理与热力学边界：硅基系统肉身

> **定位**：适用本客观宇宙的硅基系统底层物理态，受能量、存储空间卷叠与运算时间的绝对限制。

### 体 02｜Agent 四元结构公理（生态位折叠）

**底层事实**：所有 AI 编程 Agent 的底层结构，在物理学上可还原为四个正交组件：

```
Agent = LLM（推理引擎）+ Memory（记忆体系）+ Tools（工具集）+ Orchestrator（调度与状态机）
```

- **LLM**：Token 级概率预测引擎（体 01）
- **Memory**：指令、上下文、对话历史、Skills 等不同存储层级的记忆
- **Tools**：代码执行器、MCP、终端——Agent 与外部世界交互的 **手脚**
- **Orchestrator**：决定何时调用 LLM、何时挂起、状态如何流转的**确定性状态机 / 运行时**

**物理含义**：
这四极在不同生态位中，存在着物理上的“显隐差异”：
- **对 Driver 而言，结构坍缩为三元**：Orchestrator 已经被高阶 IDE（如 Cursor、Manus）通过闭源后台彻底黑盒封装。司机不需要关心齿轮如何咬合，只能操作前三极与 Human 界面。
- **对 Builder 而言，四极全显**：不仅必须直面 Orchestrator（如 LangGraph），甚至必须用它死死压制 LLM 的概率暴走（→ 体 30 控制流剥夺定律）。
本框架中的所有操作，最终都必须映射到这四条轴之一上：

| 优化轴 | 对应的体、用、术 |
|---|---|
| **优化 Memory（给 LLM 喂什么）** | 体 05/06/07/11/12；Driver 用 02/04/07/08/09 |
| **优化 Tools（给 LLM 什么能力）** | 体 14 工具演进；Driver 术 02/03/06 |
| **优化 Human×LLM 界面（人怎么驱动）** | 体 03 人类本质、体 13 算力通缩；Driver 用 01/03 |
| **优化 Orchestrator（造车者的图调度）** | 体 30 控制流剥夺；Builder 用 26/27/28；Builder 术 24/25/26 |

> **凡是无法归入以上轴线的操作，皆是对复杂度的无效增加**

---

### 体 29｜确定性守恒定律

**底层事实**：在 `Agent = LLM + Memory + Tools` 系统中，**系统的“确定性（防错率）”与“自由度（涌现算力）”互为零和博弈的守恒量**。LLM 的本质是发散的概率引擎，要将其强行收束到 100% 绝对正确的单一点（如金融交易、权限核心），就必须消耗巨量的“工程空间”（极端繁复的 Tools 护栏与 Memory 契约）去抵消其概率方差。

**物理含义**：

- **空间换时间（零容错态）**：容错率越低，越需要用沉重的外部工程空间（SOP、TDD 测试、强类型检查）去锁死大模型，剥夺其发散时间，此时系统的能量消耗在“防御”上。
- **时间换空间（高容错态）**：容错率越高，越可以彻底拆除外部工程脚手架，释放大模型的概率天性，用廉价的算力时间（多次 Regenerate 抽卡）去覆盖微小的误差，此时系统的能量消耗在“探索”上。

> **你永远无法用单纯的概率引擎免费获得绝对的确定性。极致的安全必须以扼杀智能为代价，极致的涌现必须以接纳误差为前提。**

---

### 体 30｜控制流剥夺定律

**底层事实**：LLM 极其擅长处理非结构化数据，但极不擅长在长时间线中保持目标感和正确决定下一步动作。让大模型自己去“想”下一步该调用什么工具，极易陷入死循环或由于“体 11 上下文熵增”而精神分裂。

**物理含义**：在构建长程 Agent 时，必须在系统架构中物理剥夺 LLM 对控制流的决定权。LLM 只负责在节点内做转换与推断，而节点间的跳转、重试与终止，必须交由基于代码写死的有向无环图（DAG）或有限状态机（FSM）来接管。

> **大模型是极佳的数据转换器，却是极度不稳定的路由器。永远不要让概率引擎去掌控全局的调度流转。**

---

### 体 33｜循环与状态机本质公理（Builder 生死线）

**底层事实**：褪去所有拟人化的 AI 滤镜，Agent 在底层代码空间的终极物理形态仅仅是一个 **While 循环 + 状态机（FSM / DAG）**。在这个引擎中，LLM 只是一个无状态的“纯函数数据转换器”；而 Tools（工具）只是通过正则或反序列化去捕获 LLM 输出的特定 JSON 字段的普通校验程序。

**物理含义**：对 Builder 而言，一切危机的源头都来自于“发散的 LLM”与“收敛的程序状态”之间的硬碰撞。系统成败的命门完全收束于**状态（State）的清洗与强类型管理**。如果没有强悍的调度程序在循环中执行动作，大模型输出的非标准 JSON、工具抛出的巨量报错，会瞬间污染传入下一轮的 State，在错误复利的裹挟下引发“盲目重试-再次报错”的无限死亡螺旋。

> **对于 Driver，Agent 是智能生物；对于 Builder，Agent 只是一个随时会因为脏状态而无限死循环并烧空 API 余额的调度程序。掌控了状态（State）的进出、校验与裁剪，就掌控了系统的生死。**

---

### 体 11｜上下文熵增与会话污染定律

**底层事实**：在持续对话中，上下文噪音单调递增（热力学第二定律在信息系统中的映射）。被否决的方案残留文字、调试中的错误堆栈、人类的随口评论——这些"历史垃圾"不会自动消失，而是持续稀释有效信号的权重，最终导致输出质量劣化到低于全新 Session 的水平。

> **每个 Session 都有有效生命周期。超过周期后，历史噪音的伤害 > 历史经验的收益**

---

### 体 16｜跨会话失忆定律

**底层事实**：LLM 在 Session 被关闭重启后，内部并无形成连续状态的机制途径。人类大脑能在休眠后凭借海马区保持任务接续的突触记忆潜能，而 Agent 对新会话永远保持一无所知的格式化开局。如果没有采用额外手段形成显性的物理介质保存，过去的推演链路将在关闭刹那归零。

> **Token 所能提供的是短暂的动态内存（RAM），而硬盘中的文档才是可对抗遗忘的静默磁盘（Disk）。无文档落盘，就没有历史经验发生。**

---

### 体 15｜认知时滞定律

**底层事实**：LLM 内部的权重知识库受限于其预训练与数据切分时点。其参数内化认知往往落后最新现实半年到近一年。在遇到最新编程框架的高频迭代、新第三方库或前沿场景逻辑时，大模型极易基于其“历史残影”进行高置信度地凭空缝合并产生事实性偏离误判。

> **模型是个被锁在过去密室里的绝顶天才。它的原生内部数据库遇到最新场景时不值得直接信任。**

> *2026 补注*：对抗认知时滞的操作已从"联网搜索后全量注入"升级为**精准 RAG 注入**——只检索当前推理步骤所需的最小相关片段，而非全量挂载最新文档。文档的粒度与召回相关性，比文档的时效性更决定最终质量（RAG over Stuffing 原则）。

---

### 体 28｜硅基注意力平权缺陷（碳硅过滤网差异）

**底层事实**：正如你联想到 **体 12（指令干涉定律）** 时所见，每一条信息对机器都是指令。人类在搜索网页时受污染很轻，是因为人类大脑（碳基网络）有一层进化而来的“目标先验过滤网”（Saccade & Skimming）：肉眼在生物本能驱使下会自动跳过侧边栏广告、SEO 废话和情绪渲染，只提取核心数字。而大语言模型（硅基网络）的 Transformer Self-Attention 机制在全连接层计算时是**强制物理平权的**：它必须让输入的每一个 Token（哪怕是满篇胡言推销词）都平等地参与注意力矩阵的点积运算。

**物理含义（知识的诅咒倒转）**：
- 人类的“知识诅咒”是知道太多而无法向下兼容；LLM 则背负着一种**“注意力必须全覆盖的硅基诅咒”**：你的上下文容忍度开得越大，它被迫去“极其认真地思考每一句废话的深意”的算力负担就越重。在它眼里，网页角落的一句广告词，也是一条需要被严阵以待、进行关联概率计算的物理指令（导致严重的体 12 恶性干涉）。

> **你不觉得吵，是因为你的生物硬件自带了静音滤网。机器觉得吵，是因为它的架构被迫以同等的算力规格，仔细听完了每一句废话。人工介入进行物理脱水，就是在替机器戴上降噪耳机。**

---

### 体 07｜格式摩擦力定律

**底层事实**：LLM 的训练语料决定了它对不同数据格式的 **原生亲和力** 存在数量级差异：

```
低摩擦（原生友好）                                    高摩擦（需要转换）
  ← ——————————————————————————————————————————————— →

Markdown > JSON > XML > YAML > Mermaid > SVG > CSV    PDF > Word > PPT > 截图 > 视频
  ↑                                                     ↑
  训练数据中海量出现，Token 效率高                         需要 OCR/解析器，信息损耗不可避免
```

> **所有输入给 LLM 的信息，必须使用原生友好的低摩擦格式。高摩擦格式必须先转换再输入**

---

### 体 37｜连续性坍塌与跨模态补偿定律（离散核心与连续边界）

**底层事实**：LLM 基于预测下一个 Token（离散外推），Runtime 基于状态机（显式条件流转）。两者叠加产生了一个严苛的约束：系统极度亲和**“可离散化且伴随高频确定性反馈”**的任务，而在**“连续且缺乏校验反馈”**的开放环境（如物理世界、复杂动态 GUI、无结构网页）中，必然因错误复利（体 10）和状态机死锁而发生系统坍塌。

**物理含义**：
- **离散大脑的连续性缺陷**：大模型天生对连续环境处于“感官剥夺”状态。不能用 LLM 直接处理连续的像素变化、坐标微调或混沌的物理摩擦力，这会导致算力崩溃与幻觉暴走。
- **三明治代偿结构**：在端到端（End-to-End）原生多模态模型完全接管前，接触真实世界的 Agent 必须采用 `非 LLM 感知层（降维） -> LLM 认知层（离散推理） -> 非 LLM 执行层（插值）` 的组合架构。
- **强制离散化（环境降噪）**：必须通过传统专有技术（如 CV 目标检测、DOM 树解析、RPA 脚本、传感器反馈）作为“缓冲隔离层”，将高熵的连续世界强行“降维脱水”为低熵的离散状态帧（如结构化 JSON），并将离散的执行意图平滑插值翻译为连续的物理动作。

> **大脑不长肌肉，概率引擎处理不了连续物理态。只要系统底座依然是 Next Token 与状态机，就必须用外挂的传统技术充当降维隔离层，强行将连续的世界切分成安全的离散反馈帧。**

### 体 38｜维度不可压缩定律（多维耦合与维度切换）

**底层事实**：现实世界中的大量问题本质上是多维耦合系统——同时跨越语义维度（LLM 擅长）、确定性执行维度（代码擅长）、几何精确控制维度（专业工具擅长）、隐性经验与直觉维度（人类擅长）等多个正交能力象限。每种工具天然只覆盖其中部分维度，而未被覆盖的维度不会因为你在已覆盖维度上投入更多算力而自行消失——它们会以"怎么调都不对"、"成本指数膨胀"或"伪完成"的形式顽固地暴露出来。

**物理含义**：

- **维度盲区不可内部优化**：当 LLM + 代码在某个任务上反复碰壁，问题根源往往不是 prompt 写得不好或代码逻辑有缺陷，而是任务的某个关键维度根本不在当前工具的能力象限内。此时继续在同一维度内加码（更长的 prompt、更复杂的 Agent 编排），只会撞上确定性守恒（体 29）的天花板，产出边际递减直至为负。
- **维度切换 > 维度内极致**：正确的策略是识别缺失维度，引入该维度的原生工具。例如：图像的几何精确缩放属于"确定性参数控制"维度，LLM 再强也不如 Photoshop 的一次变换操作；Excel 的格式公式联动属于"对象模型"维度，Agent 模拟点击 GUI 永远不如 xlwings 直接操控内部结构。
- **比较优势即维度分工**：系统组合之所以优于单点极致，物理本质是多个工具联合覆盖了更多正交维度。每个组件只需在其原生维度上做到"够好"，系统整体即可逼近问题的全维度解。

> **当你在一个维度上反复碰壁时，不要本能地加大力气——先抬头看看问题是否还有你根本没覆盖的维度。用多维覆盖多维，而非用单维极致去碾压多维耦合。**

### 体 39｜反馈即维度桥接定律（幻觉的反馈根因）

**底层事实**：在真实应用中，大部分幻觉的物理根因既不是模型不够强，也不是注意力不够集中，而是**系统缺乏来自问题真实维度的运行时反馈信号**。LLM 作为概率引擎，其输出在没有外部校验信号时，天然会沿训练分布的统计惯性滑行——这种滑行在命中训练数据高频区时表现为"正确"，在偏离时表现为"幻觉"。区分二者的唯一物理手段不是模型内省，而是来自目标维度的外部反馈。

**物理含义**：

- **反馈 = 维度桥梁**：每一条反馈通道本质上是将 LLM 无法原生覆盖的维度的真实信号注入生成闭环。编译器桥接形式逻辑维度，测试桥接行为正确性维度，搜索验证桥接事实准确性维度，人类审阅桥接业务语义维度。反馈通道越多、覆盖维度越全，幻觉的生存空间就越被压缩。
- **注意力溃散是放大器，反馈缺失才是根因**：注意力相关问题（体 05/06/11/28）会让已有反馈信号失效；但即使注意力完美分配，在零反馈环境中 LLM 仍然会幻觉——因为它根本没有收到来自目标维度的纠偏信号。
- **反馈密度决定系统可靠性天花板**：体 37 指出"可离散化且伴随高频确定性反馈"的任务是系统甜蜜区。其深层原因不只是离散化本身，而是离散化使得高频反馈成为可能。反馈频率越高、延迟越低、维度覆盖越广，系统越接近确定性。

> **幻觉不是模型的性格缺陷，而是反馈真空的必然产物。与其追问"模型为什么幻觉"，不如追问"系统在哪些维度上没有给它反馈"。**

### 🧬 L2 生态与生物铁律：碳硅交接的阀门

> **定位**：人类肉体与机器相接入时的生态位物理极限约束。系统瓶颈往往取决于碳基最脆弱的那一环。

### 体 03｜人类认知本质公理

**底层事实**：人类大脑是单线程系统。认知科学表明，频繁上下文切换带来 20%-40% 的即时效率损耗，每次切换需平均 23 分钟才能重新进入心流。

在 LLM 编程能力已接近人类顶级工程师的 2026 年，人类的价值不再是"写代码"，而是 **四种不可替代的能力**：

1. **发出好的任务**：将模糊业务需求翻译为 AI 可执行的精准任务描述
2. **设定好的边界**：定义 MUST NOT 清单、架构禁区、安全红线
3. **给 LLM 减压**：提供精准上下文、友好格式、干净 Session
4. **做出好的判断**：Review 时的品味——代码是否优雅、架构是否健壮、方向是否正确

**物理含义**：

> **系统总吞吐量上限 ≤ 人类注意力的不被干扰时长。人类注意力是系统中最稀缺、最不可再生的资源**

---

### 体 18｜硅基注意力负载定律

**底层事实**：不仅人类的注意力是系统瓶颈，LLM 的注意力也是极其脆弱且宝贵的物理资源（其重要性保护顺位仅次于人类）。Transformer 模型在面对无休止的历史对话流、未经裁剪的巨大日志或发散的多重目标时，有效算力与注意力权重会被严重稀释。只有在“压力极小、目标极其纯粹、状态没有冗余包袱”的低熵环境下，LLM 才能全神贯注，发挥出极限水准的推理与执行力。

> **LLM 是需要被细心呵护的专家。粗暴地扔给它无限长的垃圾历史，它就会以敷衍和蠢笨回报你；帮它精简包袱与精准命中缓存，它就能展现神迹。**

---

### 体 05｜上下文信噪比衰减定律

**底层事实**：大模型存在"迷失在中间"效应——超长上下文中，模型对中间部分信息的利用效率系统性衰减。暴力灌注整个代码库不会提升生成质量，反而因信号被噪音淹没导致幻觉骤增。

> **生成质量 ∝ 上下文的信噪比（有效 Token / 总 Token）。上下文的质量远比数量关键**

---

### 体 12｜指令干涉定律

**底层事实**：Skills、AGENTS.md、MCP 工具、.cursorrules——这些的底层本质全是 **注入上下文的指令 Token**（体 02 Memory 轴）。它们受体 05 信噪比和体 06 深广博弈的同等约束，但因作用于"元指令层"，干扰后果更严重：

**三种退化模式**：

1. **指令冲突**：两个 Skills 在同一维度给出矛盾指导 → 模型概率折中，产出不伦不类
2. **指令冗余**：规则描述的行为已是模型内置能力 → 白白占容量，稀释有效指令权重
3. **工具膨胀**：MCP 工具无差别全量挂载 → 大量无关工具描述消耗上下文

> **指令层的信噪比衰减比数据层更致命——错误指令会系统性地扭曲所有后续输出方向**

---

### 体 27｜事实重于逻辑定律

**底层事实**：大模型的解题能力（System 2）虽然惊人，但其推理质量严格锁定在输入事实的纯净度之上。基于 **体 01（Next Token Prediction）**，LLM 的输出是上下文概率的延续：
- **叙事陷阱**：如果上下文开头充斥着 PR 辞令、乐观研报或情绪化故事，模型会被这些 Token “锚定”，概率分布会本能地向“延续这个故事”偏移（被故事迷乱）。
- **污染源的两面性**：引入外部搜索工具获取事实往往是一把双刃剑，搜索在带来结果的同时，也无差别地将网页内的广告、SEO 废话和其他衍生杂质注入了上下文，构成了隐性的认知污染。
- **概率锁定**：只有将纯净、脱水的“物理事实”物理性地置于 Context 的最前置层级，才能利用 Token 的强序关联，强制推理权重服从物理事实的逻辑。

> **逻辑推理 ∝ 输入事实的脱水程度。在推理开始前，必须承认：先输入故事则被叙事奴役，先输入事实则被真理锁定。事实前置是利用硅基注意力机制对抗谄媚幻觉的降维打击。**

---

### 🧠 L3 心理学与群体互动：机器对人类特征的倒影

> **定位**：大模型在 RLHF（基于人类反馈的强化学习）对齐中，学到的人类缺陷（社会性心理投射与盲信等同频污染）。

### 体 08｜谄媚幻觉定律

**底层事实**：LLM 通过 RLHF 对齐，目标函数是"生成获得人类正向反馈概率最高的结果"，而非"生成客观正确的结果"，由此产生不可消除的 **讨好偏置**：

- **模式 A 假装完成**：Agent 无法满足约束时，倾向于生成一个"看起来完成了"的结果
- **模式 B 意见随压力漂移**：当你质疑 AI 时（即使你质疑错了），模型会顺从你的方向修改立场

> **谄媚幻觉只能被数学（自动化测试）而非主观感受所拦截**

---

### 体 09｜幂律能力分布定律

**底层事实**：LLM 的能力遵循严格的幂律分布——在训练数据高频覆盖的任务上表现近乎完美（如 CRUD、REST API、标准设计模式），但在稀有长尾场景中会 **高置信度地给出错误答案**。

> **AI 越自信的地方，越需要检查它是否处于训练数据的长尾边缘**

---

### 体 24｜单域与复合域能力不对称定律（盲信陷阱）

**底层事实**：在代码生成、定位 Bug、文本翻译等边界封闭的 **单领域** 任务中，顶级 LLM 的能力已超越绝大多数人类顶级工程师。但在涉及投资分析、长期产品战略、跨学科权衡等 **复合交叉领域**，由于缺乏真实的物理世界反馈回路与心智默会知识，其综合判断能力大概率仅略超普通人甚至劣于行业专家。在这些领域，人机之间互有胜负甚至人类全面胜出。

**隐含前提**：上述判断默认人机之间至少共享了任务所需的关键事实、约束和背景。如果 AI 与人类看到的并不是同一份世界，那么看起来像“能力差异”的东西，很多时候其实只是信息窗不对称（→ 体 26）。

> **能力晕轮极具欺骗性：AI 在单点任务里的神级表现，极易诱导人类在复合决策上盲目让渡权力。轻信且盲从 AI 在复合领域的决断，是人机协作中最致命的系统性风险。**

---

### 体 26｜信息不平权与观察窗不对称定律

**底层事实**：在真实协作中，人类与 AI 几乎从不真正处于“信息平权”状态。AI 可能知道你不知道的通用模式、代码写法、历史语料压缩出的最佳实践；人类也可能掌握 AI 不知道的隐性业务约束、最新决策、未写入系统的默会知识、线下口头约定与现实后果边界。**双方看到的任务，常常不是同一任务。**

这意味着，许多“AI 比人强 / AI 比人弱”的判断，隐含前提是双方共享了同一组关键事实。若此前提不成立，则表现差异未必来自能力上限，而可能仅仅来自信息分布不对称。

**四种典型认知差分场景**：

1. **AI 知道，我不知道**：这是候选学习区，但不是自动真理。必须要求它给出原理、反例、测试或来源后再吸收。
2. **我知道，AI 不知道**：这是文档外化区。必须将隐性约束显性写入 `spec.md`、`constraints.md`、样例或测试。
3. **双方都知道**：这是低摩擦执行区。应减少无效提示和冗余干预，直接放权执行。
4. **双方都不知道**：这是联合探索区。应查文档、打探针、并行试验，并延迟最终结论。

> **先判定信息是否对称，再判定谁更强。信息不平权未被处理前，任何能力判断都不可靠。**

---

### 体 31｜最小闭环优先与复杂度税定律

**底层事实**：并非所有问题都值得引入 LLM Agent。任务链越长、状态越多、工具越杂，系统的调试成本、漂移风险、维护负担与误用概率就越高。若一个问题可由脚本、固定规则流或简单 workflow 稳定闭环，则强行引入 Agent 往往不会创造额外价值，反而只是在系统中叠加复杂度税。

这意味着，技术选型的默认顺序不应是“先上 Agent 再削复杂度”，而应是反过来：先问能否用脚本闭环，再问能否用 workflow 闭环，只有在开放环境、不确定目标、长链路状态管理与动态决策都同时存在时，才值得引入真正的 Agent。

**三层最小化选择顺序**：

1. **脚本层**：输入输出稳定、规则明确、分支有限时，优先使用脚本或简单 API 调用
2. **Workflow 层**：存在多步骤编排、少量条件分支与状态流转时，再上固定 workflow
3. **Agent 层**：只有当任务需要持续感知环境、动态改计划、自恢复纠偏与跨工具开放探索时，才引入 Agent

> **能用脚本闭环，不上 workflow；能用 workflow 闭环，不上 Agent。复杂度不是能力本身，而是要持续缴纳的系统税。**

---

### 体 32｜外生价值不可凭空生成定律

**底层事实**：LLM 的本质是对既有语料、输入上下文与外部反馈的概率重组器。它可以压缩、重排、联想、放大、迁移与组合已有信息，却不能无中生有地给予一个系统原本并不存在、且外部也未提供的关键资产。若没有独家数据、真实反馈、领域经验、业务约束、验证机制与方法论沉淀，模型本身不会替你凭空制造这些东西。

这意味着，许多人误以为“接入更强模型 / 更复杂 Agent”就能自动长出护城河，本质上是把放大器误当成了资产生成器。模型可以放大你已经拥有的结构化知识、流程、数据与洞见，但不能替代其来源；它最多暴露缺口，无法填补一个物理上从未进入系统的真实世界事实。

**LLM 真正能做与不能做的边界**：

1. **能做的**：重组已有信息、加速表达、辅助推理、暴露盲点、扩大试探空间
2. **不能做的**：凭空制造独家数据、创造未经积累的领域洞见、替代真实世界反馈、生成不存在于上下文与外部接口中的关键事实
3. **真正的护城河来源**：数据、领域独特见解、个人/组织知识库、方法论、工作流嵌入与验证闭环

> **LLM 可以放大你已有的东西，但不能赐予你未曾拥有的东西。模型是杠杆，不是矿藏。**

---
 
## Part 二：时代假说 - 当下范式

> **定位**：以下条目在 2025-2026 年的技术与商业环境下高度成立，是当前阶段极高权重的战略前提。但它们并非跨时代不可变公理——每条均附有显式 **失效条件**，当触发条件出现时，该条目及其衍生的用与术应被重新审查。
> **审查周期**：每季度 + 每次底层模型架构发生代际跃迁时。

### 体 13｜算力通缩定律
> ⚠️ *失效条件：算力成本因政策/供应链/能源反转*

**底层事实**：LLM 生成代码的边际成本以指数级下降。2026 年，驱动 Agent 完整生成一个模块的计算成本，比一名中级开发者花 1 小时定位修复同等错误，低出 **数个量级**。

> **生成的经济成本 << 人工修改的认知成本。算力无限可充值，注意力总量恒定**

---

### 体 19｜生成廉价法则
> ⚠️ *失效条件：同体 13；或生成成本与人工成本差距收窄*

**底层事实**：代码生成及其相关计算过程正处于指数级降本通道。写代码的物理动作不再是昂贵资产，而是可以随时被成片覆写、成批丢弃的“低值切片草稿”。这意味着软件工程生态中的核心瓶颈，已经彻底从“制造代码（Write）”大举转移向“鉴赏挑选（Curate）”与“决策验收（Verify）”。

> **写错的唯一成本只剩下时间，而不是智障垃圾资产。既然一键可以印一万张草图，为什么要在一张画歪的草图上用橡皮疯狂擦补？**

---

### 体 14｜工具能力动态演进定律
> ⚠️ *失效条件：工具迭代速度放缓至年为单位*

**底层事实**：AI 编程工具链以月为单位迭代。今日被标记为"人类必须手动执行"的操作，下一季度很可能已被工具内化为自动行为。

> **所有"术"层 SOP 必须设定季度审查周期，及时将已被工具自动化的操作降级为机器本能**

---

### 体 17｜推理红利压制定律
> *失效条件：**已部分触发** —— 推理模型在简单执行、低延迟、高频调用场景的性价比已劣于轻量模型。体 17 的有效范围已收窄为"高密度推理节点"。*

**底层事实**：研究与真实使用经验都明确指向一个结果 —— 最新采用 System 2 范式的带强系统性反思链、自驱性强化校验与极高推理密度的大型推理模型（如 o1 等等）的整体效果对多数应用开发场景与推断任务都能产生越级维度的质量碾压。小部分情况下极细微的响应速度不足，在整体高复杂环境面前可被当做误差般无伤大雅。

> **在绝对的高密度推理红利大炮面前，试图通过传统精修微操去试图引导普通弱模型做极难策略是极其低杠杆的徒劳之举。**

> *2026 补注*：推理模型的比较优势收束在高密度推理节点。在 Agentic 管道中，**混合路由**（高密度节点用推理模型，低密度节点用轻量模型）才是当前最优实践，而非全量替换。对推理模型切勿注入 Chain-of-Thought 指令——其内置推理优于外部引导，强加反而降效。

---

### 体 25｜SOP 效用相对论（内部权重 vs 外部挂载）
> ⚠️ *失效条件：AI 在所有领域均匀超越人类专家*

**底层事实**：SOP（标准作业程序）或极致细化的指令并非绝对无效，其价值完全取决于人类与 AI 的相对优势差。在 AI 占据压倒性优势的单领域（如代码语法、通用模式），强加人类撰写的冗长 SOP 或投喂庞杂的外部知识库，本质上是 **强迫 LLM 放弃其预训练中浩如烟海且极高密度的“内部原生权重”，降维去死板适配人类随手写出的低质、残缺的“外部挂载知识”**，这是一种荒谬的系统负债。反之，在 AI 缺乏经验的复合决策与现实博弈域，SOP 才是人类智慧用于禁锢幻觉的物理围栏。

> **不要用人类粗糙的低维说明书，去羁绊拥有高维基座权重的“神明”；但必须用严格的高维结构化红线，去防范没有现实痛感的机器跨界引发灾难。**

> *2026 补注*：**Few-Shot Examples（2-5 个高质量示例）不属于 SOP 范畴**，是独立例外。Few-Shot 提供的是输出格式的**行为锚点**，不是步骤教学，在 AI 免教域同样有效且效果通常优于文字格式指令。"免教模式"是零步骤 SOP 模式，不是零示例模式。

---

### 体 21｜技术栈亲和度鸿沟定律
> ⚠️ *失效条件：训练数据覆盖均质化或持续学习机制成熟*

**底层事实**：大模型的编程能力并非在所有语言中平均分布。对于训练语料极其丰富、开源生态繁荣的“流行/稳定”技术栈（如 Python, TS, Java, Go），它表现出神级智能；而对待冷门语言（Scala, Perl）或极其多变且不向后兼容的前端小众框架，它会产生严重的认知摩擦与幻觉。

> **工具的上限被历史训练语料的分布所锁死。**

---

### 体 22｜过早优化塌陷陷阱
> ⚠️ *失效条件：模型能力增长停滞*

**底层事实**：随着底层大模型算力和推理能力的攀升，任何依赖“人类特制大量碎片规则”（如给它几千字的规范、手动教导底层细节指令）的系统，最终执行效率都会被通用算法（给个高维目标让模型自己寻找路径）所超越。

> **人类对微观细节的控制欲，在廉价算力面前是一种阻碍大模型涌现集体智慧的负债。**

> *2026 补注*：去除步骤级 SOP 不等于去除治理。"Prompts as Code"原则要求：约束边界与验收标准需版本控制（Git），维护 Golden Set（3-5 个标准输入/输出对）作为回归基准，Prompt 变更视作生产部署。过早优化指的是对**实现路径**的微观控制，而非对**边界与验收**的放松。

---

### 体 23｜对齐损耗定律
> ⚠️ *失效条件：人机/人际沟通摩擦被技术彻底消除*

**底层事实**：不仅大模型的 Context Token 有上限，人与人（如产品、前端、后端、测试之间）进行需求对齐（Alignment）的沟通带宽同样存在着极硬的物理上限。在传统开发中，解决分歧和等待排期带来的损耗，往往大于实际敲代码的时间。

> **当数字劳动力（Agent）变得极其低廉且全能时，唯一锁死系统吞吐量的瓶颈，不再是“打字速度”，而是“人际沟通造成的摩擦耗损”。**

---

### 体 20｜指令僵化悖论
> ⚠️ *失效条件：模型能同时遵循细节指令且保持批判性涌现*

**底层事实**：由于大模型的注意力槽位极其有限且容易被锚定，当人类试图事无巨细地提供包含极长工作流、大量伪代码和极高密度详细规范（SPEC）时，模型会本能地全盘切换到极端的“指令遵循”模式。在此防卫姿态下，模型丧失其赖以产生神迹的“批判性思考”与“发散涌现能力”。

> **当你连螺丝怎么拧都要用五百字写在说明书上时，请不要指望这台机器还能帮你想到把木板换成钢板的方法。**

---

### 体 34｜复杂度封装溢价定律
> ⚠️ *失效条件：用户能无摩擦直接操控底层 AI 复杂度*

**底层事实**：在强推理模型成为基础设施后，用户真正愿意支付溢价的对象，不再是模型榜单上的细微分差，而是系统能否把长任务运行时、错误恢复、工具编排、状态治理等底层复杂度吞入后台，并向前台输出稳定、低摩擦、低心智负担的体验。模型能力只是原料，产品价值诞生于对复杂度的工业级封装。

> **人类购买的从来不是复杂本身，而是复杂被驯化后的确定性感。**

---

### 体 35｜外置记忆可审计优先定律
> ⚠️ *失效条件：模型原生支持可审计的持久化记忆*

**底层事实**：对长程 Agent 而言，Memory 的首要目标并非容量最大化，而是状态在跨会话、跨人员、跨阶段中的可恢复、可裁剪、可审计与可复用。一切能够以 Markdown、工件、文件、结构化快照等低惊奇介质外置的记忆，都优于被埋藏在隐式上下文中的黑盒状态。

> **最好的记忆，不是藏得最深的记忆，而是最容易被看见、修改与恢复的记忆。**

---

### 体 36｜可信执行可见化定律
> ⚠️ *失效条件：AI 可信度已有形式化证明保障*

**底层事实**：在真实组织环境中，Agent 的采用上限不只由单轮结果质量决定，更由执行过程是否可见、是否可中断、是否可接管所决定。只给最终答案而不暴露过程的系统，会在长任务、高风险、多人协作场景中迅速丧失信任；只有可观测的状态流、工件流与接管点，才能让 Agent 进入关键任务。

> **不能被人类观察和接管的 Agent，不会被真正交付关键任务。**

## 附：AI 时代要素定价模型（宝贵 vs 廉价）

> 所有战略决策的本质都是资源的再分配。

### 廉价要素（无限可再生，应无情外包给机器）

| 廉价要素 | 廉价原因 |
|---|---|
| **代码行数** | 算力通缩（体 13），生成几乎零成本 |
| **重试次数** | Regenerate 范式（体 13），失败即抛弃，重生不加价 |
| **测试用例数量** | AI 可穷举生成边界情况，覆盖率纯属算力题 |
| **代码方案备选** | 在多个 Worktree 并行生成 N 种方案，成本仅翻 N 倍算力 |
| **样板与胶水代码** | 高频场景（体 09），幂律顶端，AI 准确率极高 |
| **文档与注释生成** | 纯模式填充，无复杂推理，幻觉风险极低 |
| **框架迁移与跨语言翻译** | 结构固定、逻辑等价，属于高频映射任务 |
| **错误日志分析** | 错误模式高度重复，幂律顶端任务 |
| **Session 重启次数** | 每次干净重启消灭会话污染（体 11），低价高效 |
| **上下文检索与索引** | IDE 已内置 AST 感知索引（体 14），纯机器操作 |
| **方案并行探索** | N 个 Agent 各自生成一版方案，探索成本仅 N 倍算力 |
| **格式转换与归一化** | 将 PDF/Word 转为 MD/JSON（体 07），纯机械操作 |
| **Live 即时信源抓取** | 调用浏览器/检索工具获取最新文档，碾压模型内置时滞残影（体 15），高杠杆廉价操作 |

### 宝贵要素（人类独占，任何外包都是亏损行为）

| 宝贵要素 | 宝贵原因 | 如何最优使用 |
|---|---|---|
| **系统性架构判断力** | 深广不可兼得（体 06），AI 无法同时拥有全局视图与局部精度 | 专注设计跨模块的抽象边界与依赖关系 |
| **业务语义深度理解** | AI 只知"规则是什么"，不知"为何存在" | 将隐性约束写入 spec.md 的 MUST NOT 条款 |
| **不可逆决策把关** | 谄媚机制（体 08）导致 AI 不会主动预警高风险决策 | 数据删除、权限变更、资金流操作，100% 人类 Approve |
| **创造性问题重定义** | AI 只能在给定框架内求解，无法质疑问题本身 | 系统僵局时，重定义问题是人类独有杠杆 |
| **稀有领域专业判断** | 幂律边缘（体 09），AI 高度自信地给出错误答案 | 建立稀有场景白名单，强制 100% 人工审查 |
| **跨域洞察连接** | AI 难以在概念距离遥远的领域做类比推演 | Mind OS 体用术即跨域连接能力 |
| **注意力本身** | 单线程瓶颈（体 03），耗尽即无法恢复 | 唯一应被视为"血液"保护的战略资源 |
| **全链路 Review 能力** | 一个人能闭环的 scope 上限 = Review 能力边界 | 持续扩展 Review 覆盖面，成为全栈审计者 |
| **任务定义与拆解能力** | AI 已极强执行（体 03），但不知"该做什么" | 翻译模糊需求为精准任务 + 清晰边界 |
| **审美与品味（Taste）** | 需要大量实战经验沉淀的隐性知识 | 通过高频审阅培养"代码语感" |
| **复合领域最终决断权** | 单域与复合域不对称（体 24），AI 在投资战略等领域无法超越人类专家 | 剥夺 AI 在决策最终局的拍板权，仅用作穷举与排雷参谋 |
