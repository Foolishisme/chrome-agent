docs(governance): implement minimal entropy repository governance & pruning

This commit implements the "Current State Only" document governance strategy to mitigate agentic entropy and "old-fact pollution", significantly reducing the AI context burden.

Changes:
1. Workspace Pruning (Archive & Delete)
- Physically removed highly polluting history logs (doc/logs/*).
- Deleted multi-level redundant folders containing obsolete workflows and discussions: doc/history/, doc/other/, doc/review/, doc/汇报/.
- Cleaned up doc/reference/ to only keep core architecture guidelines: design_principles.md, pitfalls.md, and success_patterns.md. Removed severely outdated files like thread_bootstrap.md.

2. Git Ignore Policies
- Evicted the remaining 3 core reference files from Git tracking to freeze their historical state.
- Explicitly added these reference paths into .gitignore to strictly physically isolate them from the AI's default context window.

3. Structural Re-alignment
- The doc/ directory is now strictly confined to a 2-level hierarchy: Level 1 for Current State constraints, and Level 2 for ignored references.

This shift marks the transition from an "append-only log" system to a strict "overwrite-only checkpoint" discipline, protecting the Browser Core V2 architecture from speculative regressions.
